# DiStore — Kidswear

Website toko baju anak modern dan responsif untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `style.css` — seluruh styling
- `script.js` — filter, pencarian, wishlist, cart counter, WhatsApp

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save, lalu tunggu GitHub Pages selesai deploy.

## WhatsApp
Nomor sudah diset ke `0822 1313 3961` dan pesan awal:
`halo kakak aku mau pesen dong.....`

Jika ingin mengganti nomor atau template pesan, edit variabel `WA_NUMBER` dan `WA_MESSAGE` di `script.js`.
